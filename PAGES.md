# GitHub Pages — RINGFORGE

## Live now

Project Pages on `ringforge-nexus` cannot be created by `GITHUB_TOKEN`.
Actions log: `Create Pages site failed. Error: Resource not accessible by integration`.

The console is published on the existing user site (Pages already enabled):

**https://antmanthepro.github.io/ringforge/**

Hub plate: **https://antmanthepro.github.io/**

## Enable project Pages (one click)

This cannot be done from Actions. Owner must:

1. Open https://github.com/AntManThePro/ringforge-nexus/settings/pages
2. Build and deployment → Source → **GitHub Actions**
3. Save
4. Actions → GitHub Pages → Run workflow

After that, https://antmanthepro.github.io/ringforge-nexus/ will also serve the console.

Do not commit `ACCESS.txt`. Gate is wanderer friction, not a vault.
